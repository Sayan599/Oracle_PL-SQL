# `MEMBER OF` and `SUBMULTISET OF`

This lesson demonstrates two Oracle SQL collection conditions using nested-table collections.

## `MEMBER OF`

`MEMBER OF` checks whether a value appears in a collection. 

The condition evaluates to `TRUE` when the value is present.

```sql
SET SERVEROUTPUT ON;

DECLARE
    TYPE T_NUM IS TABLE OF PLS_INTEGER;
    V_NUMS T_NUM := T_NUM(10, 20, 30);
    NUM INTEGER := 10;
BEGIN
    IF NUM MEMBER OF V_NUMS THEN
        DBMS_OUTPUT.PUT_LINE('THIS IS PRESENT INSIDE');
    END IF;
END;
/
```

**Expected output:**

```text
THIS IS PRESENT INSIDE
```

Here, `NUM` is `10`, and `10` is an element of `V_NUMS`.

## `SUBMULTISET OF`

`SUBMULTISET OF` checks whether every element in one collection is contained in another collection. The left-hand collection is tested against the collection on the right.

```sql
SET SERVEROUTPUT ON;

DECLARE
    TYPE T_NUM IS TABLE OF PLS_INTEGER;
    V_NUMS1 T_NUM := T_NUM(10, 20, 30);
    V_NUMS2 T_NUM := T_NUM(10, 20);
BEGIN
    IF V_NUMS2 SUBMULTISET OF V_NUMS1 THEN
        DBMS_OUTPUT.PUT_LINE('THIS IS SUBMULTISET OF V_NUMS1');
    END IF;
END;
/
```

**Expected output:**

```text
THIS IS SUBMULTISET OF V_NUMS1
```

`V_NUMS2` contains `10` and `20`, both of which are present in `V_NUMS1`, so the condition is true.

## Collection type note

Both examples use nested tables. The original lesson notes describe these conditions as applicable to nested tables and not to associative arrays or varrays. Check the Oracle documentation for the specific database version and collection type when applying these conditions elsewhere.
